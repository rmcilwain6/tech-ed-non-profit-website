# Security

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private vulnerability reporting on this repository (Security tab, "Report a vulnerability").

Include what you found, how to reproduce it, and what impact you think it has. We will acknowledge reports within a week. This is a small volunteer-run project, so fixes may take longer; we will keep you informed.

## Scope

This site is static. It has no accounts, no database and no forms that collect personal information. Reports that matter most here:

- Anything that would let someone change site content or deploys.
- Secrets or personal information accidentally committed to the repository.
- Third-party requests, cookies or tracking that the site should not be making.
- Dependencies with known vulnerabilities that affect the built site.

Linked external systems (for example, grant application forms) are run separately and have their own reporting routes.
